# Security review, 24 Oct 2026

Internal review of Dispatch 0.3.0, by its developer. No external audit yet.

## Scope

Permissions, network, storage, crypto, exported components, and the new About and Erase everything screens.

## Findings

- **Permissions.** None. The merged release manifest has no `<uses-permission>`; the AndroidX `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` is removed on purpose (no receiver is registered at run time). Package visibility uses `<queries>` for `SEND` and `SEND_MULTIPLE` only.
- **Network.** No `INTERNET` permission, so no socket can be opened. Links in About (email, sidali.dev) are handed to the mail app or the browser on an explicit tap.
- **Exported components.** `MainActivity` (launcher) and `ShareActivity` (share target) are exported, as they must be. `ShareActivity` forwards the received intent to the component the user tapped, with read grants and only the write grant it received. `ClipProvider` is not exported, read-only, and serves only file names matching a strict pattern from the no-backup directory (no path traversal).
- **Storage.** One private SharedPreferences file (pinned, hidden, one switch, last used only when on) and at most three image copies in `noBackupFilesDir`. `allowBackup=false`, data extraction rules exclude every domain from cloud backup and device transfer.
- **Crypto.** None is needed: there is no secret, no account and no network. SHA-256 is used only to show the signing certificate's fingerprint.

## Fixed in this review

- There was no way to delete Dispatch's data short of uninstalling. Added "Erase everything" (type ERASE to confirm): it clears the preferences and the files, cache and no-backup directories.
- The home screen said "Nothing ever leaves your phone", while Copy, Copy image and Save do hand content to other apps when you ask. Replaced by a "What leaves your device" screen that says exactly what goes where, with the same facts in PRIVACY.md.
- The installed APK's signing certificate is now visible in About, to compare with SECURITY.md.

## What remains

- No release key yet, so no published fingerprint. To do with the first release. (Done on 31 Oct 2026 for 0.4.0: see SECURITY.md.)
- The repository is private: the claims above cannot be checked by others yet.
- No MobSF report or OWASP MASVS grid archived yet.
- Erasing deletes files but cannot guarantee the flash is wiped (see THREAT_MODEL.md).
